# BOSS 新标签页沟通助手 v0.1.1

一个面向 Chrome / Edge 的轻量浏览器扩展。点击 BOSS 职位页的“立即沟通”时，尝试在新的活动标签页中进入该岗位的 HR 聊天，同时保留原岗位列表。

## 安装

1. 解压压缩包到固定位置。
2. Chrome 打开 `chrome://extensions/`，Edge 打开 `edge://extensions/`。
3. 开启 **开发者模式**。
4. 选择 **加载已解压的扩展程序**，选择内含 `manifest.json` 的文件夹。
5. 在已登录的 BOSS 直聘岗位搜索页刷新页面，再点击右上方“立即沟通”。

## 原理

1. 在原页面从选中职位卡片/右侧详情中读取明确的职位详情链接（无法确认时不猜测）。
2. 拦截该次用户点击，在一个新的前台标签页打开该岗位详情。
3. 在新页等待原生“立即沟通”按钮出现后尝试单次点击，由 BOSS 官方页面处理导航。

## 隐私与功能边界

- 仅匹配 `www.zhipin.com`，不向第三方服务器发送任何信息。
- 不自动输入或发送聊天消息，不批量投递、不读取登录 Cookie。
- 如果职位链接无法可靠定位，则不接管该按钮，BOSS 原生点击逻辑仍会执行（可能在原页跳转）。
- 若 BOSS 不接受脚本触发的原生点击，可能停留在新开的职位详情；请在新页手动点“立即沟通”。
- BOSS 改版后，页面选择器可能需要相应调整。

## 验证情况

- 已完成 JavaScript 语法检查、MV3 manifest JSON 校验和本地模拟验证。
- 本地模拟验证覆盖：原列表未导航、只打开一个前台标签页、打开选中的职位详情、只触发一次详情页沟通按钮。
- 由于缺少已登录的 BOSS 现场环境，未完成真实站点端到端验证。不要把模拟结果等同于真实网站兼容性保证。
